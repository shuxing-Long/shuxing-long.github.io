# 向量变换基础

## 1. 什么是向量变换

对向量进行**平移**、**旋转**、**收缩**等操作的行为称为**向量变换**。简单地说，就是使向量发生改变的操作。

形式上，向量变换是一个函数 $T$，输入一个向量，返回一个新的向量：

$$
T: \mathbb{R}^n \to \mathbb{R}^m
$$

## 2. 旋转

### 实现方法

利用极坐标进行旋转：先转为极坐标 → 调整角度 → 转回笛卡尔坐标。

```python
def rotate(angle, vectors):
    polar = to_polar(vectors)        # 转极坐标
    new_angle = polar[1] + angle     # 添加旋转角度
    return to_cartesian((polar[0], new_angle))  # 转回笛卡尔坐标
```

### 三维旋转

三维空间中，旋转是绕某个轴进行的：

```python
def rotate_z(angle, vector):
    x, y, z = vector
    new_x, new_y = rotate2d(angle, (x, y))
    return new_x, new_y, z

def rotate_x(angle, vector):
    x, y, z = vector
    new_y, new_z = rotate2d(angle, (y, z))
    return x, new_y, new_z

def rotate_y(angle, vector):
    x, y, z = vector
    new_x, new_z = rotate2d(angle, (x, z))
    return new_x, y, new_z
```

> 想象 x、y、z 是三根穿过茶壶的不同方向的铁丝，旋转函数就是绕某根铁丝旋转。

## 3. 平移

```python
def translate(translation, vectors):
    return [(v[0] + translation[0], v[1] + translation[1]) for v in vectors]
```

## 4. 缩放

```python
def scale_by(scalar):
    def new_function(v):
        return (v[0] * scalar, v[1] * scalar, v[2] * scalar)
    return new_function
```

## 5. 函数组合

将多个变换组合成一个新变换：

```python
def compose(f1, f2):
    def new_function(input):
        return f1(f2(input))
    return new_function
```

> ⚠️ 变换的顺序很重要！先缩放再平移 ≠ 先平移再缩放。例如，先平移再缩放会将平移量也缩放。

## 6. 柯里化 (Currying)

将接收多个参数的函数转化为接收单个参数的函数链：

```python
def curry2(f):
    def g(x):
        def new_function(y):
            return f(x, y)
        return new_function
    return g

# 使用示例
scale_by = curry2(scale)
scale_by(2)((1, 2, 3))  # → (2, 4, 6)
```

## 7. 规则多边形生成

利用极坐标将圆周 $2\pi$ 等分，获取多边形顶点：

```python
def regular_polygon(n):
    return [to_cartesian((1, 2 * pi * k / n)) for k in range(n)]
```

> 当 $n=3$ 时：$k=0 \to 0$ 弧度, $k=1 \to \frac{2\pi}{3}$ (120°), $k=2 \to \frac{4\pi}{3}$ (240°)

## 8. 多边形映射

对三维模型的每个三角形面应用变换：

```python
def polygon_map(transformation, polygons):
    return [
        [transformation(vertex) for vertex in triangle]
        for triangle in polygons
    ]
```
