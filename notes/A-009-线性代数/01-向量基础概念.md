# 向量基础概念

## 1. 用代码学习数学的好处

1. **精确性**：设计必须精确，以便计算机理解，且永远不会让新符号产生歧义。
2. **聚焦抽象**：可以避免进行复杂的运算，只需关注数学的抽象概念与性质。

## 2. 什么是向量

- **向量**是多维空间中的对象。
- 二维世界中需要使用**两个信息**来描述其具体位置：水平位置和垂直位置。
- 为了描述点在二维平面中的位置，还需要一个参考点：**原点**。
- **二维向量**是平面上相对于原点的一个点。

> 简单来说：向量 = 有大小和方向的量。在坐标系中，向量由从原点出发的有向线段表示。

## 3. 二维向量的表示

以原点为坐标轴的 0 点，建立一个 $(x, y)$ 坐标轴。向量 $\vec{v} = (x, y)$ 表示从原点 $(0, 0)$ 到点 $(x, y)$ 的有向线段。

### 示例：用向量绘制恐龙

给定一系列顶点坐标 `dino_vectors`，可以绘制出恐龙的轮廓：

```python
dino_vectors = [
    (6,4), (3,1), (1,2), (-1,5), (-2,5), (-3,4), (-4,4),
    (-5,3), (-5,2), (-2,2), (-5,1), (-4,0), (-2,1), (-1,0),
    (0,-3), (-1,-4), (1,-4), (2,-3), (1,-2), (3,-1), (5,1)
]
```

将这些点依次用线段连接起来，就构成了恐龙的轮廓图。

## 4. 关键概念

| 概念 | 说明 |
|------|------|
| 向量 | 多维空间中的对象，有大小和方向 |
| 原点 | 坐标参考点，通常为 $(0, 0)$ |
| 坐标轴 | 水平和垂直方向的参考线 |
| 二维向量 | 平面上相对于原点的点，表示为 $(x, y)$ |
