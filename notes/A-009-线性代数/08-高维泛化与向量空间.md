# 高维泛化与向量空间

## 1. 泛化向量的定义

### 超越"箭头"

泛化向量的核心思想：**向量不仅仅是"箭头"，而是任何满足向量空间八条公理的对象**。

泛化向量可以是：

- **n 维数组** $\mathbb{R}^n$ — 从 2、3 维推广到任意 n 维
- **多项式** $a_0 + a_1x + a_2x^2 + \cdots + a_nx^n$
- **函数** $f: \mathbb{R} \to \mathbb{R}$ — 函数空间
- **矩阵** $M_{m \times n}$ — 矩阵加法和标量乘法构成向量空间
- **数列** — 收敛数列、无穷数列等

> 一旦接受泛化向量的定义，所有线性代数工具（线性组合、基、维数、线性变换、内积、特征值）都可以应用到这些对象上。

## 2. 向量空间的公理化定义

向量空间 $V$ 定义在数域 $\mathbb{F}$（通常为 $\mathbb{R}$ 或 $\mathbb{C}$）上，满足以下**8 条公理**：

### 加法公理（4 条）

| 公理 | 名称 | 公式 |
|------|------|------|
| 1 | 交换律 | $\vec{u} + \vec{v} = \vec{v} + \vec{u}$ |
| 2 | 结合律 | $(\vec{u} + \vec{v}) + \vec{w} = \vec{u} + (\vec{v} + \vec{w})$ |
| 3 | 零元存在 | $\exists \vec{0} \in V,\ \vec{v} + \vec{0} = \vec{v}$ |
| 4 | 逆元存在 | $\forall \vec{v} \in V,\ \exists (-\vec{v}) \in V,\ \vec{v} + (-\vec{v}) = \vec{0}$ |

### 标量乘法公理（4 条）

| 公理 | 名称 | 公式 |
|------|------|------|
| 5 | 标量结合律 | $a(b\vec{v}) = (ab)\vec{v}$ |
| 6 | 标量单位元 | $1 \cdot \vec{v} = \vec{v}$ |
| 7 | 标量对向量的分配律 | $a(\vec{v} + \vec{w}) = a\vec{v} + a\vec{w}$ |
| 8 | 标量加法对向量的分配律 | $(a + b)\vec{v} = a\vec{v} + b\vec{v}$ |

### 推论

- 加法封闭性：$\vec{u} + \vec{v} \in V$
- 标量乘法封闭性：$a \cdot \vec{v} \in V$
- $0 \cdot \vec{v} = \vec{0}$
- $(-1) \cdot \vec{v} = -\vec{v}$

## 3. Python 实现：抽象基类

```python
from abc import ABC, abstractmethod

class Vector(ABC):
    """向量抽象基类"""

    @abstractmethod
    def add(self, other):
        """向量加法：v + w"""
        ...

    @abstractmethod
    def mul(self, scalar):
        """标量乘法：a * v"""
        ...

    @abstractmethod
    def zero(self):
        """返回零向量"""
        ...

    def __neg__(self):
        """取反：-v"""
        return self.mul(-1)

    def __sub__(self, other):
        """减法：v - w = v + (-w)"""
        return self.add(-other)
```

## 4. 泛化坐标向量实现

```python
class CoordinateVector(Vector):
    """用元组存储坐标的泛化向量"""

    def __init__(self, *coordinates):
        self.coordinates = coordinates

    def add(self, other):
        return type(self)(*(
            a + b for a, b in zip(self.coordinates, other.coordinates)
        ))

    def mul(self, scalar):
        return type(self)(*(
            scalar * c for c in self.coordinates
        ))

    def zero(self):
        n = len(self.coordinates)
        return type(self)(*[0] * n)
```

## 5. 验证向量空间公理（随机化测试）

```python
def test_vector_space(equal, a, b, u, v, w):
    zero = v.zero()
    assert equal(u + v, v + u)          # 公理1: 交换律
    assert equal(u + (v + w), (u + v) + w)  # 公理2: 结合律
    assert equal(v + zero, v)           # 公理3: 零向量
    assert equal(v + (-v), zero)        # 公理4: 逆元
    assert equal(a * (b * v), (a * b) * v)  # 公理5: 标量结合律
    assert equal(1 * v, v)              # 公理6: 标量单位元
    assert equal(a * (v + w), a * v + a * w)  # 公理7
    assert equal((a + b) * v, a * v + b * v)  # 公理8
```

## 6. 核心洞察

> "高维泛化"的真正威力不在于"画不出 100 维的图"，而在于**函数、多项式、矩阵都可以当作向量来处理**。所有适用于向量的线性代数工具都可以自然地应用到这些对象上。
