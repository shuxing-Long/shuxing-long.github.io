# 线性方程组与交点

本章对应《程序员数学》第 7 章：把“解方程组”翻译成 Python，并用于小行星游戏的碰撞检测。核心思想是：**两条直线的交点，就是两个线性方程的共同解**。

## 1. 从两点到直线方程

给定平面上两个点 $v_1=(x_1,y_1)$、$v_2=(x_2,y_2)$，可以把它们所在的直线写成标准形式：

$$
ax + by = c
$$

其中：

$$
a = y_2-y_1,\qquad b = x_1-x_2,\qquad c = x_1y_2-y_1x_2
$$

对应源码：

```python
def standard_form(v1, v2):
    x1, y1 = v1
    x2, y2 = v2
    a = y2 - y1
    b = x1 - x2
    c = x1 * y2 - y1 * x2
    return a, b, c
```

## 2. 方程组与矩阵形式

两条直线：

$$
\begin{cases}
a_1x + b_1y = c_1\\
a_2x + b_2y = c_2
\end{cases}
$$

可以写成矩阵方程：

$$
\begin{pmatrix}a_1&b_1\\a_2&b_2\end{pmatrix}
\begin{pmatrix}x\\y\end{pmatrix}
=
\begin{pmatrix}c_1\\c_2\end{pmatrix}
$$

也就是：

$$
M\mathbf{x}=\mathbf{c}
$$

用 NumPy 求解：

```python
import numpy as np

def intersection(u1, u2, v1, v2):
    a1, b1, c1 = standard_form(u1, u2)
    a2, b2, c2 = standard_form(v1, v2)
    m = np.array(((a1, b1), (a2, b2)))
    c = np.array((c1, c2))
    return np.linalg.solve(m, c)
```

`np.linalg.solve(m, c)` 就是“数值解线性方程组”的接口，等价于求 $M^{-1}c$。

## 3. 几何意义

- 一个线性方程 $ax+by=c$ 表示一条直线。
- 两个线性方程联立，表示求两条直线的公共点。
- 若矩阵不可逆，通常表示两条直线**平行或重合**，此时可能无解或有无穷多解。
- 平行线调用 `np.linalg.solve` 会抛出 `LinAlgError`。

## 4. 应用：线段相交与碰撞检测

小行星游戏中，飞船的激光和障碍物都是线段。判断两条线段是否相交，分两步：

1. 求两条线段所在直线的交点。
2. 检查交点是否同时落在两条线段上。

```python
from vectors import distance

def do_segments_intersect(s1, s2):
    u1, u2 = s1
    v1, v2 = s2
    d1, d2 = distance(*s1), distance(*s2)
    try:
        x, y = intersection(u1, u2, v1, v2)
        return (distance(u1, (x, y)) <= d1 and
                distance(u2, (x, y)) <= d1 and
                distance(v1, (x, y)) <= d2 and
                distance(v2, (x, y)) <= d2)
    except np.linalg.LinAlgError:
        return False
```

### 为什么不能只靠“肉眼看图”

线段相交看起来是几何问题，但计算机只能用数值计算。把几何问题转成**线性方程组**，就能复用 NumPy 等稳定实现。

## 5. 小结

- 直线方程 $ax+by=c$ 的系数可以完全由两个点确定。
- 两条直线求交点，就是解一个 $2\times 2$ 线性方程组。
- 线段相交 = 直线有交点 + 交点在两条线段范围内。
- 平行线会导致矩阵不可逆，代码必须捕获异常。
