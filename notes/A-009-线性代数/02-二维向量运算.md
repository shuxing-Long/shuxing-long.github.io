# 二维向量运算

## 1. 向量加法

### 公式

$$
(x_1, y_1) + (x_2, y_2) = (x_1 + x_2,\ y_1 + y_2)
$$

### 几何意义

原向量添加新向量，意味着**移动或平移**一个现有的点或点的集合。向量加法相当于在平面上沿某个方向平移。

### Python 实现

```python
def add(v1, v2):
    return (v1[0] + v2[0], v1[1] + v2[1])

# 支持任意多个向量相加
def add(*vectors):
    return tuple(map(sum, zip(*vectors)))
```

### 性质

- **交换律**：$u + w = w + u$
- **结合律**：$(u + v) + w = u + (v + w)$

## 2. 向量的分量与长度

### 分量

将向量分成 $(x, 0) + (0, y)$ 的形式。这在现实中有重要意义——人不可能一直走直线，需要拐弯。

### 长度（模）

利用**勾股定理**计算向量长度：

$$
\|(x, y)\| = \sqrt{x^2 + y^2}
$$

```python
from math import sqrt

def length(v):
    return sqrt(v[0]**2 + v[1]**2)
```

> 例如向量 (4, 3) 的长度为 $\sqrt{4^2 + 3^2} = \sqrt{25} = 5$。

## 3. 标量乘法

### 公式

$$
s \cdot (x, y) = (sx, sy)
$$

### 几何意义

- 运算的效果是将向量按给定的系数进行**缩放 (scale)**。
- 乘以大于 1 的数 → 伸长
- 乘以 0 到 1 之间的数 → 缩短
- 乘以负数 → 方向反转 + 缩放

> 标量乘法的性质：将坐标按照系数 $s$ 缩放，向量的长度以同等系数缩放。即 $\|s \cdot \vec{v}\| = |s| \cdot \|\vec{v}\|$。

```python
def scale(s, v):
    return (s * v[0], s * v[1])
```

## 4. 减法、位移与距离

### 负向量

对于任一向量 $u$，负向量 $-v$ 具有相同的长度，但指向**相反的方向**。

向量和其负向量的长度相等：$\|(a,b)\| = \|(-a,-b)\| = \sqrt{a^2 + b^2}$。

$u + (-u) = (0, 0)$，即回到原点。

### 减法

$$
(x_1, y_1) - (x_2, y_2) = (x_1 - x_2,\ y_1 - y_2)
$$

几何意义：$v - w = v + (-w)$。

### 位移 vs 距离

| 概念 | 类型 | 说明 |
|------|------|------|
| 位移 | 向量 | 两个向量之间的差，有方向 |
| 距离 | 标量 | 两个向量之间的差的长度（即三角形的斜边） |

### Python 实现

```python
def subtract(v1, v2):
    return (v1[0] - v2[0], v1[1] - v2[1])

def distance(v1, v2):
    return length(subtract(v1, v2))
```

### 周长计算示例

```python
def perimeter(vectors):
    distances = [
        distance(vectors[i], vectors[(i + 1) % len(vectors)])
        for i in range(len(vectors))
    ]
    return sum(distances)
```

## 5. 核心关系图

```
向量加法 → 平移 (位移)
向量减法 → 位移 (向量)
差的长度 → 距离 (标量)
标量乘法 → 缩放
```
