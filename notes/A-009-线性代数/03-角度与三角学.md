# 角度与三角学

## 1. 角度到分量

### 极坐标

使用**角度**（量角器）和**距离**（尺子）组成的坐标称为**极坐标**。极坐标方便旋转操作。

### 三角函数关系

已知距离 $r$ 和角度 $\theta$：

$$
x = r \cdot \cos\theta, \qquad y = r \cdot \sin\theta
$$

$$
\cos\theta = \frac{x}{r}, \qquad \sin\theta = \frac{y}{r}, \qquad \tan\theta = \frac{y}{x}
$$

> **sin**：垂直距离（y 轴方向）→ 正弦
> **cos**：水平距离（x 轴方向）→ 余弦
> **tan**：$\tan\theta = \frac{\sin\theta}{\cos\theta}$ → 正切

### 极坐标 vs 笛卡尔坐标

| 坐标系 | 优势 | 表示 |
|--------|------|------|
| 极坐标 | 方便旋转 | $(r, \theta)$ |
| 笛卡尔坐标 | 方便平移 | $(x, y)$ |

## 2. 弧度

### 基本关系

- $1 \text{ 弧度} \approx 57.296^\circ$
- $\pi \text{ 弧度} = 180^\circ$

### 转换公式

$$
\text{弧度} = \text{度数} \times \frac{\pi}{180}
$$

$$
\text{度数} = \text{弧度} \times \frac{180}{\pi}
$$

> ⚠️ Python 的 `sin`、`cos`、`tan` 等函数使用**弧度**计算，使用前需要将角度转换为弧度。

## 3. 坐标转换

### 极坐标 → 笛卡尔坐标

```python
from math import sin, cos

def to_cartesian(polar_vector):
    length, angle = polar_vector[0], polar_vector[1]
    return (length * cos(angle), length * sin(angle))

# 示例：长度=5，角度=37° → 转换为弧度后计算
angle = 37 * pi / 180
to_cartesian((5, angle))  # → (3.99, 3.01)
```

### 笛卡尔坐标 → 极坐标

```python
from math import atan2

def to_polar(vector):
    x, y = vector[0], vector[1]
    angle = atan2(y, x)  # atan2 自动处理象限
    return (length(vector), angle)
```

> ⚠️ 使用 `atan2(y, x)` 而非 `atan(y/x)`，因为 `atan2` 能正确处理 $x=0$ 的情况和不同象限。

## 4. 特殊角度的三角函数值

| 角度 | 弧度 | $\sin$ | $\cos$ | $\tan$ |
|------|------|--------|--------|--------|
| 0° | 0 | 0 | 1 | 0 |
| 30° | $\pi/6$ | $\frac{1}{2}$ | $\frac{\sqrt{3}}{2}$ | $\frac{1}{\sqrt{3}} \approx 0.577$ |
| 45° | $\pi/4$ | $\frac{\sqrt{2}}{2}$ | $\frac{\sqrt{2}}{2}$ | 1 |
| 60° | $\pi/3$ | $\frac{\sqrt{3}}{2}$ | $\frac{1}{2}$ | $\sqrt{3} \approx 1.732$ |
| 90° | $\pi/2$ | 1 | 0 | 无定义 |
| 180° | $\pi$ | 0 | -1 | 0 |

## 5. 角度范围与正负

- 第一象限（0°～90°）：sin > 0, cos > 0, tan > 0
- 第二象限（90°～180°）：sin > 0, cos < 0, tan < 0
- 第三象限（180°～270°）：sin < 0, cos < 0, tan > 0
- 第四象限（270°～360°）：sin < 0, cos > 0, tan < 0
