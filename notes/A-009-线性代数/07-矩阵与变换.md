# 矩阵与变换

## 1. 用矩阵表示线性变换

### 核心思想

线性变换 $T$ 对应一个矩阵 $A$，其中第 $i$ 列就是 $T(\vec{e}_i)$（即对标准基向量做变换的结果）。

对一个向量 $\vec{v}$ 做线性变换 $T$，等价于将矩阵 $A$ 乘以 $\vec{v}$：

$$
T(\vec{v}) = A\vec{v}
$$

### 从变换推导矩阵

```python
def infer_matrix(n, transformation):
    def standard_basis_vector(i):
        return tuple(1 if j == i else 0 for j in range(1, n + 1))

    standard_basis = [standard_basis_vector(i) for i in range(1, n + 1)]
    cols = [transformation(v) for v in standard_basis]
    return tuple(zip(*cols))
```

### 矩阵-向量乘法

```python
def multiply_matrix_vector(matrix, vector):
    return tuple(
        sum(v_entry * m_entry for v_entry, m_entry in zip(row, vector))
        for row in matrix
    )

# 等价写法：每行与向量的点积
def multiply_matrix_vector_dot(matrix, vector):
    return tuple(dot(row, vector) for row in matrix)
```

## 2. 矩阵乘法

### 前提条件

两个矩阵 $A$（$m \times n$）和 $B$（$n \times p$）能够相乘，当且仅当：**$A$ 的列数等于 $B$ 的行数**。

乘积 $C = A \times B$ 的维度为 $m \times p$。

### 计算规则

结果矩阵 $C$ 中的元素 $c_{ij}$ = $A$ 的第 $i$ 行与 $B$ 的第 $j$ 列的**点积**：

$$
c_{ij} = \sum_{k=1}^{n} a_{ik} \cdot b_{kj}
$$

```python
def matrix_multiply(a, b):
    return tuple(
        tuple(dot(row, col) for col in zip(*b))
        for row in a
    )
```

### 性质

| 性质 | 说明 |
|------|------|
| 结合律 | $(A \times B) \times C = A \times (B \times C)$ |
| 分配律 | $A \times (B + C) = A \times B + A \times C$ |
| **不满足交换律** | $A \times B \neq B \times A$（一般情况） |

> 矩阵乘法不满足交换律，这是一个非常重要的特征。

## 3. 单位矩阵

### 定义

单位矩阵是一个**方阵**（$n \times n$），主对角线为 1，其余为 0：

$$
I_2 = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix},\quad
I_3 = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{pmatrix}
$$

### 核心性质

- $I \times A = A$（左乘保持）
- $A \times I = A$（右乘保持）
- 对应**恒等变换**——"什么也不做"的变换
- 是矩阵求逆的基准：$A \times A^{-1} = A^{-1} \times A = I$

> 单位矩阵在矩阵运算中的角色，类似于数字 "1" 在标量乘法中的角色。

## 4. 矩阵的幂

```python
def matrix_power(power, matrix):
    result = matrix
    for _ in range(1, power):
        result = matrix_multiply(result, matrix)
    return result
```

例如：旋转 90° 矩阵的 4 次幂 = 旋转 360° = $I_2$。

## 5. 线性映射投影

三维向量在 xy 平面上的投影是一个二维向量：

$$
\text{project}_{xy}(x, y, z) = (x, y)
$$

其对应矩阵为 $2 \times 3$ 矩阵：

$$
\begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \end{pmatrix}
$$

> 当第一个矩阵的列数等于第二个矩阵的行数时，矩阵才能相乘。
> 将 $n \times m$ 的矩阵乘以 $m \times q$ 的矩阵，得到 $n \times q$ 的矩阵。

## 7. 齐次坐标平移（"神奇矩阵"）

### 问题

平移不是线性变换（因为 $T(0) \neq 0$），无法用 $2 \times 2$ 矩阵直接表示二维平移。

### 解决方案：升维

将二维点 $(x, y)$ 嵌入 $z=1$ 平面，即表示为 $(x, y, 1)$（齐次坐标），然后用 $3 \times 3$ 矩阵：

$$
M = \begin{pmatrix}
1 & 0 & a \\
0 & 1 & b \\
0 & 0 & 1
\end{pmatrix}
$$

计算：

$$
M \begin{pmatrix} x \\ y \\ 1 \end{pmatrix} = \begin{pmatrix} x + a \\ y + b \\ 1 \end{pmatrix}
$$

去掉 $z$ 坐标得 $(x+a, y+b)$，完成平移！

> ⚠️ **关键限制**：这个"神奇矩阵"仅在 $z=1$ 平面上才正确。若图形放在 $z=c$ 平面，则平移量会变为 $(ca, cb)$。齐次坐标中第三个分量本质上是平移的权重。

### 同时旋转与平移

```python
rotate_and_translate = (
    (0, -1, 3),   # 旋转 + x方向平移
    (1,  0, 1),   # 旋转 + y方向平移
    (0,  0, 1)    # 齐次坐标的"1"
)
```

## 8. 矩阵即线性变换

> 每个矩阵都表示一个线性变换，每个线性变换都可以用矩阵表示。

- 二维：$2 \times 2$ 矩阵表示从 $\mathbb{R}^2 \to \mathbb{R}^2$ 的线性变换
- 三维：$3 \times 3$ 矩阵表示从 $\mathbb{R}^3 \to \mathbb{R}^3$ 的线性变换
- 投影：$2 \times 3$ 矩阵表示从 $\mathbb{R}^3 \to \mathbb{R}^2$ 的线性映射
