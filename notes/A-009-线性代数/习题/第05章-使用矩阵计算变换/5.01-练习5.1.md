```python
def infer_matrix(n, transformation):
    def standard_basis_vector(i):
        return tuple(1 if i==j else 0 for j in
range(1,n+1))      ←---- 创建第i个标准基向量表示一个元组，在第 i个
坐标中包含 1 ，在所有其他坐标中包含 0
    standard_basis = [standard_basis_vector(i) for i in
range(1,n+1)]      ←---- 创建标准基表示 n个向量的列表
    cols = [transformation(v) for v  in standard_basis]
←---- 将矩阵的列定义为对标准基向量进行相应线性变换的结果
    return tuple(zip(*cols))      ←---- 按照惯例，将矩阵重构为
行元组，而不是列的列表
可以用类似 rotate_z_by(pi/2) 这样的线性变换来进行测试。
```
