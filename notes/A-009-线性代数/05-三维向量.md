# 三维向量

## 1. 三维向量基础

三维向量是包含**大小**、**方向**和**高度**的向量，包含二维向量的所有信息。

二维向量可视为高度为 0 的三维向量：$(x, y, 0)$。

## 2. 三维向量运算

### 加法

$$
(x_1, y_1, z_1) + (x_2, y_2, z_2) = (x_1 + x_2,\ y_1 + y_2,\ z_1 + z_2)
$$

### 标量乘法

$$
s \cdot (x, y, z) = (sx, sy, sz)
$$

### 减法

$$
(x_1, y_1, z_1) - (x_2, y_2, z_2) = (x_1 - x_2,\ y_1 - y_2,\ z_1 - z_2)
$$

### 长度

$$
\|(x, y, z)\| = \sqrt{x^2 + y^2 + z^2}
$$

```python
from math import sqrt

def length(v):
    return sqrt(sum([coord ** 2 for coord in v]))
```

> 规律延伸：$(1,1)=\sqrt{2}$，$(1,1,1)=\sqrt{3}$，$(1,1,1,1)=2$

### 球坐标系

在三维空间中，一个向量由**长度 $r$**、**角度 $\theta$**（方位角）和**角度 $\phi$**（极角）来描述。

## 3. 点积 (Dot Product) — 测量向量对齐

### 定义

$$
\vec{u} \cdot \vec{v} = u_x v_x + u_y v_y + u_z v_z
$$

### 几何意义

点积是计算两个向量之间的**对齐情况**：

| 点积 | 夹角 | 含义 |
|------|------|------|
| $> 0$ | $< 90^\circ$ | 方向大致相同 |
| $= 0$ | $= 90^\circ$ | 相互垂直 |
| $< 0$ | $> 90^\circ$ | 方向大致相反 |

通俗理解：利用乘法的负负得正、正负得负、正正得正来判断角度。

### 点积与角度

$$
\vec{u} \cdot \vec{v} = \|\vec{u}\| \|\vec{v}\| \cos\theta
$$

$$
\theta = \arccos\left( \frac{\vec{u} \cdot \vec{v}}{\|\vec{u}\| \|\vec{v}\|} \right)
$$

```python
def dot(u, v):
    return sum([c1 * c2 for c1, c2 in zip(u, v)])

from math import acos

def angle_between(v1, v2):
    return acos(dot(v1, v2) / (length(v1) * length(v2)))
```

### 重要性质

- **几何意义**：$\vec{a} \cdot \vec{b}$ 是 $|\vec{a}|$ 在 $|\vec{b}|$ 方向上的**投影**
- **标量乘法**：$(s\vec{u}) \cdot \vec{v} = \vec{u} \cdot (s\vec{v}) = s(\vec{u} \cdot \vec{v})$
- **自身点积**：$\vec{u} \cdot \vec{u} = \|\vec{u}\|^2$

> 点积的取值范围：长度为 3 和 7 的两向量，点积在 $-21$ 到 $21$ 之间。

## 4. 向量积/叉积 (Cross Product) — 测量向量垂直

### 特点

- **仅适用于三维向量**
- 输出是一个**向量**（垂直于两个输入向量）
- 用于定义方向

### 公式

$$
\vec{u} \times \vec{v} = (u_y v_z - u_z v_y,\ u_z v_x - u_x v_z,\ u_x v_y - u_y v_x)
$$

```python
def cross(u, v):
    ux, uy, uz = u
    vx, vy, vz = v
    return (uy*vz - uz*vy, uz*vx - ux*vz, ux*vy - uy*vx)
```

### 叉积的长度

$$
\|\vec{u} \times \vec{v}\| = \|\vec{u}\| \|\vec{v}\| \sin\theta
$$

几何意义：等于以 $\vec{u}$ 和 $\vec{v}$ 为边的**平行四边形面积**。

> $\|\vec{v}\| \cdot \sin\theta$ 相当于平行四边形的高（对应 y 轴方向）。

### 右手规则

用右手食指指向 x 轴，弯曲三根手指指向 y 轴，拇指指向 z 轴方向。叉积结果的方向由右手定则确定。

> 镜子中的坐标轴方向与原图不同：在原图中 x 轴正半轴在 y 轴正半轴的顺时针方向，镜子中则相反。

### 性质验证

$(0, 0, 1)$ 与任意向量 $\vec{v}$ 的叉积的 z 坐标恒为 0。因为决定 z 坐标的是 x 和 y，而 $(0,0,1)$ 的 x 和 y 都是 0。

## 5. 三维渲染（投影到二维平面）

### 核心思想

利用点积提取三维向量在给定方向上的分量，将三维投影到二维：

```python
def component(v, direction):
    return dot(v, direction) / length(direction)

def vector_to_2d(v):
    return (component(v, (1,0,0)), component(v, (0,1,0)))
```

### 法向量

一个面的法向量垂直于该面：

```python
def normal(face):
    return cross(
        subtract(face[1], face[0]),
        subtract(face[2], face[0])
    )
```

### 渲染算法

- 对于每个面，计算单位法向量
- 只渲染法向量 z 分量为正的面（指向观察者）
- 用法向量与光源方向的点积计算阴影程度

> 三维对象的表面都可以表示成**三角形的集合**，每个三角形由代表其顶点的三个向量定义。
