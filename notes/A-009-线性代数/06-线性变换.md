# 线性变换

## 1. 什么是向量变换

向量变换是将向量作为输入并返回新向量的函数。对向量进行平移、旋转、收缩操作的行为统称为向量变换。

## 2. 线性变换的定义

线性变换是**保持向量和与标量乘积**的向量变换 $T$，满足以下两条性质：

### 性质一：保持向量加法

$$
T(u) + T(v) = T(u + v)
$$

### 性质二：保持标量乘法

$$
T(sv) = sT(v)
$$

### 关键推论

- **保持原点**：$T(0) = 0$。只有不移动原点的变换才是线性的。
- 若 $T(0) \neq 0$，则 $T$ 必然不是线性变换。
- **恒等变换** $I(v) = v$ 是线性变换。

### 反例：非线性变换

坐标平方变换 $S(v) = S(x, y) = (x^2, y^2)$ 不是线性的：

$$
S(sv) = s^2 \cdot S(v) \neq s \cdot S(v)
$$

例如 $s=2, v=(1,1)$：$S(2,2) = (4,4)$，但 $2 \cdot S(1,1) = (2,2)$。

## 3. 线性组合

一个向量集合的**线性组合**是它们的标量乘积之和：

$$
c_1 \vec{v}_1 + c_2 \vec{v}_2 + \cdots + c_n \vec{v}_n
$$

```python
def linear_combination(scalars, *vectors):
    scaled = [scale(s, v) for s, v in zip(scalars, vectors)]
    return add(*scaled)
```

## 4. 标准基

### 三维标准基

$$
\vec{e}_1 = (1, 0, 0),\quad \vec{e}_2 = (0, 1, 0),\quad \vec{e}_3 = (0, 0, 1)
$$

### 二维标准基

$$
\vec{e}_1 = (1, 0),\quad \vec{e}_2 = (0, 1)
$$

**任何三维向量都可以被分解为标准基的线性组合**。例如：

$$
(3, 2, 5) = 3\vec{e}_1 + 2\vec{e}_2 + 5\vec{e}_3
$$

## 5. 用标准基确定线性变换

这是线性代数中最核心的思想之一：

> 知道了线性变换 $T$ 对标准基向量的作用结果，就可以确定 $T$ 对**任意**向量的作用结果。

设 $\vec{v} = c_1\vec{e}_1 + c_2\vec{e}_2 + c_3\vec{e}_3$，则：

$$
T(\vec{v}) = T(c_1\vec{e}_1 + c_2\vec{e}_2 + c_3\vec{e}_3) = c_1 T(\vec{e}_1) + c_2 T(\vec{e}_2) + c_3 T(\vec{e}_3)
$$

### 数据量

- **三维**：需要 3 个向量（共 9 个数）确定一个线性变换
- **二维**：需要 2 个向量（共 4 个数）确定一个线性变换

```python
def transform_standard_basis(transform):
    return transform((1,0,0)), transform((0,1,0)), transform((0,0,1))
```

## 6. 线段保持

两个向量之间线段上的每个点都是形如 $s\vec{u} + (1-s)\vec{v}$ 的**加权平均值**。

线性变换的优美性质：**对线段上的点应用线性变换后，它们仍然位于线段上**。

## 7. 线性变换的组合

如果 $S$ 和 $T$ 都是线性变换，则 $S \circ T$（$S$ 和 $T$ 的组合）也是线性变换。

### 示例：相对 x 轴的镜像

$S_x(x, y) = (x, -y)$ 是线性变换：

- 保持加法：$S_x(u + v) = S_x(u) + S_x(v)$
- 保持标量乘法：$S_x(c\vec{u}) = c \cdot S_x(\vec{u})$

## 8. 小结

1. 线性变换是保持向量和与标量乘积的变换。
2. $T(0) = 0$ 是线性的必要条件。
3. 标准基的变换结果可以唯一确定整个线性变换。
4. 线性变换保持线段（不会弯曲直线）。
5. 两个线性变换的组合仍然是线性变换。
