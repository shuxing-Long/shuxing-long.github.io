## 第二章：二维向量

### 练习 2.7 — 任意数量向量相加

> 实现新的 add 函数，接收任意多个向量作为参数。

```python
def add(*vectors):
    return tuple(sum(coord) for coord in zip(*vectors))
```

### 练习 2.8 — 平移函数

> 实现函数 `translate(translation, vectors)`。

```python
def translate(translation, vectors):
    return [(v[0] + translation[0], v[1] + translation[1]) for v in vectors]
```

### 练习 2.25 — 距离与周长

```python
def distance(v1, v2):
    return length(subtract(v1, v2))

def perimeter(vectors):
    distances = [
        distance(vectors[i], vectors[(i + 1) % len(vectors)])
        for i in range(len(vectors))
    ]
    return sum(distances)
```

### 练习 2.42 — 旋转函数

```python
def rotate(angle, vectors):
    polar = to_polar(vectors)
    radian = angle * pi / 180
    return to_cartesian((polar[0], polar[1] + radian))
```

def regular_polygon(n):

### 练习 3.13 — 证明标量乘法与点积

证明 $(s\vec{u}) \cdot \vec{v} = \vec{u} \cdot (s\vec{v}) = s(\vec{u} \cdot \vec{v})$：

设 $\vec{u} = (a, b, c)$，$\vec{v} = (x, y, z)$：
$(sa, sb, sc) \cdot (x, y, z) = sax + sby + scz = s(ax + by + cz) = s(\vec{u} \cdot \vec{v})$

## 第四章：线性变换

### 练习 4.10 — 证明坐标平方变换非线性

$S(x,y) = (x^2, y^2)$。当 $s=2, v=(1,1)$ 时：
$S(2,2) = (4,4)$，但 $2 \cdot S(1,1) = (2,2) \neq (4,4)$。
因此 $S(sv) \neq sS(v)$，S 不是线性变换。

### 练习 4.11 — $T(0) \neq 0$ ⇒ 非线性

若 $T(0) \neq 0$，则 $T(v) = T(v + 0) \neq T(v) + T(0)$，所以 $T$ 不保持加法。

### 练习 4.13 — 中点公式

$(5,3)$ 和 $(-2,1)$ 的中点：$\frac{1}{2}(5,3) + \frac{1}{2}(-2,1) = (\frac{3}{2}, 2)$

### 练习 4.17 — 线性变换的组合也是线性变换

若 $S$ 和 $T$ 都是线性变换，则 $S \circ T$ 保持加法和标量乘法，因此也是线性变换。

### 练习 4.21 — 用标准基计算 B(v)

已知 $B(\vec{e}_1) = (0,0,1)$，$B(\vec{e}_2) = (2,1,0)$，$B(\vec{e}_3) = (-1,0,-1)$，$\vec{v} = (-1,1,2) = -\vec{e}_1 + \vec{e}_2 + 2\vec{e}_3$。

$B(\vec{v}) = -B(\vec{e}_1) + B(\vec{e}_2) + 2B(\vec{e}_3) = -(0,0,1) + (2,1,0) + 2(-1,0,-1) = (0,1,-3)$
